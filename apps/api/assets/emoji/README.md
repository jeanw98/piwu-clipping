# Biblioteca de objetos (Motion Graphics)

SVG planos de **Microsoft Fluent Emoji (Flat)** — licencia MIT (ver `LICENSE`).
Fuente: https://github.com/microsoft/fluentui-emoji

- `<slug>.svg`: un objeto por archivo (ej. `palm-tree.svg`, `crab.svg`).
- `index.json`: `{slug, name, group, keywords}` para buscar por nombre/palabra clave.

Uso previsto: Claude pide objetos por nombre en inglés y el código los ubica y anima
sobre un escenario procedural. (Integración en el renderer: pendiente.)
