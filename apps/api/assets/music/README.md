# Música de fondo (Motion Graphics)

Pon aquí **una pista sin derechos por tema**, en MP3, con estos nombres exactos:

| Archivo | Tema |
| --- | --- |
| `tech.mp3` | tecnología / IA |
| `space.mp3` | espacio / ciencia ficción |
| `news.mp3` | noticias |
| `nature.mp3` | naturaleza |
| `danger.mp3` | peligro / alerta |
| `money.mp3` | economía / dinero |
| `health.mp3` | salud |

- Suena en bucle a volumen ~0.15 debajo de la voz.
- Si falta la pista de un tema, el video sale **sin música y sin error**.
- Usa solo música con licencia que permita uso comercial en redes (YouTube Audio Library, Pixabay Music, etc.). Guarda la licencia junto al archivo si aplica.
- Recomendado: 60–90 s, 128 kbps, mono o estéreo, sin voces.
